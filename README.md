# dev-toolkit

A curated collection of tools and apps I use in my development workflow.

## Tools

| Name | Description | Open Source | Download |
|---|---|:---:|---|
| LocalBG | Offline AI background remover for images, videos, and GIFs — processes everything locally, no uploads. | ❌ | [localbg.app](https://localbg.app) |
| Upscayl | Free AI image upscaler that enlarges and enhances low-res images using Real-ESRGAN + Vulkan. | ✅ | [github.com/upscayl/upscayl](https://github.com/upscayl/upscayl) |
| YTDownloader (by Andreww) | GUI video/audio downloader supporting hundreds of sites, built on yt-dlp. | ✅ | [github.com/aandrew-me/ytDownloader](https://github.com/aandrew-me/ytDownloader) |
| VSCodium | Community-built, telemetry-free binary distribution of VS Code. | ✅ | [vscodium.com](https://vscodium.com) |
| VirtualBox | Cross-platform virtualization software for running virtual machines. | ✅ | [virtualbox.org](https://www.virtualbox.org/wiki/Downloads) |
